확실한 건 알아서,
애매한 것만 딱 물어봅니다.

용량은 차는데 뭘 지우고, 옮기고, 남길지 모르겠죠. 클린메이트는 확신 있는 건 알아서 처리하고, 애매한 것만 3~4개 질문으로 되묻습니다.

아예 잠금

시스템·앱 설정·미동기화 클라우드. 건드리지 않습니다.

02 — 직접 해보기

내 폴더로 엔진 돌려보기

● 파일은 브라우저를 한 바이트도 떠나지 않습니다. 서버도, 업로드도 없어요. 탭을 닫으면 사라집니다.

Downloads · 바탕화면 · 프로젝트 폴더에서 가장 잘 맞습니다. 아무것도 삭제하지 않아요 — 분석만 합니다.

이 브라우저는 지원되지 않아요. 폴더 접근(File System Access API)이 필요해서 Chrome이나 Edge 데스크톱에서 열어주세요. Safari·Firefox는 아직 이 기능이 없습니다.
03 — 솔직하게

이 데모의 한계

브라우저는 절대 경로를 알려주지 않습니다. 그래서 고르신 폴더 이름을 루트로 삼아 판단해요. AppData·WinSxS·구글 드라이브 캐시 같은 시스템 경로 규칙은 데스크톱 앱에서만 온전히 작동합니다. 실제 앱에서는 39만 파일 89GB를 질문 3개로 정리했고, 규칙 커버리지는 99.6%였어요.
