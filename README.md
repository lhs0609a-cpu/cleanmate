## 개발 환경

**CLI는 의존성이 0이다.** Node 24 타입 스트리핑만 쓴다 — `npm install` 없이 바로 돈다.

```bash
npm run scan -- "C:/Users/you/Downloads"   # 설치 불필요
npm test                                    # 설치 불필요
```

웹 데모(`web/`)만 vite가 필요하다:

```bash
npm install && npm run dev
npm run build
```

> ⚠️ **Google Drive 폴더에서 `npm install` 하지 말 것.**
> 동기화 I/O 때문에 5분+ 걸리다 죽는다 (로컬 디스크는 **3초**). Drive에 node_modules를
> 두면 수천 개 파일을 동기화하려 들고 파일 잠금까지 걸어 삭제도 안 된다.
> **로컬 클론에서 작업한다** (`C:\dev\cleanmate`). GitHub이 진실의 원천이고,
> Drive 사본은 소스만 둔다. CLI는 의존성이 없어서 Drive에서도 그냥 돈다.

## 배포

GitHub → Vercel 자동 배포. `master`에 푸시하면 프로덕션에 나간다.

`vercel.json`의 **`connect-src 'none'`** — 데모가 사용자 파일을 읽으므로
브라우저가 네트워크를 강제 차단한다. *"파일은 기기를 떠나지 않습니다"* 를 말이 아니라
배포 설정으로 증명한다. 우리 코드가 데이터를 보내려 해도 브라우저가 막는다.

## 검증 결과 (실측)

핵심 가정 — *"존 B를 결정적 미지수로 묶으면 질문 3~4개로 대량을 해결할 수 있는가?"* → **참.**

| 대상 | 파일 | 용량 | 질문 | 질문당 해결 | 규칙 커버리지 |
|---|---|---|---|---|---|
| Downloads | 243 | 14.8GB | 4 | 3.71 GB/질문 | 86.8% |
| AppData/Local | 390,825 | 89.2GB | **3** | **8.94 GB/질문** | **99.6%** |

Downloads에서는 **질문 1개가 13.9GB(94%)를 해결**했다.

## 프로토타입이 잡아낸 실제 오탐

지식 DB가 없었으면 그대로 사고였을 것들. 전부 회귀 테스트로 잠갔다(`src/knowledge/paths.test.ts`).

1. **구글 드라이브 캐시 함정** — `AppData\Local\Google\DriveFS`의 메타데이터 DB 26.5GB를
   "평범한 큰 파일"로 보고 *"옮길까요?"* 라고 제안했다. 옮겼으면 드라이브 동기화가 통째로 깨진다.
   원인: 규칙이 `Google Drive`(공백)만 찾고 실제 경로 `Google\DriveFS`를 놓침.
   → 기획서 원본에 적힌 창업 인사이트를 프로토타입이 스스로 재현했다.
2. **WSL/Docker `.vhdx`** — 이동·삭제 대상으로 분류됐다. 실제로는 compact 전용.
3. **설치된 앱 안의 node_modules** — 사용자 프로젝트로 오인(635곳). 지우면 앱이 깨진다.
4. **Alfred 워크플로** — `workflows`를 경로 끝에서만 찾아 디렉토리 형태를 놓쳤다.
   CleanMyMac이 실제로 이걸 날린 사례가 있다.

수정 후: 존 C 잠금 648MB→**41.8GB**, 규칙 커버리지 86.8%→**99.6%**, 질문당 해결 3.71→**8.94GB**.
**안전과 효과가 함께 좋아졌다.**

## 설계

```
scanner.ts     원시 사실만 수집. 판단 없음. (나중에 MFT로 교체)
  ↓
classify.ts    3-존 판정. 규칙 확증분만 존 A 자격 (R1 방어선)
  ↓
engine.ts      미지수 클러스터링 → 레버리지 점수 → 질문 3~4개
```

**knowledge/paths.ts 가 제품의 핵심 자산이다.** 두꺼울수록 콜드스타트(R2)가 해결되고
LLM 오분류(R1)에 덜 의존한다.

### 안전 불변식

- 모르는 파일은 **절대 SAFE로 추측하지 않는다** → AMBIG(물어봄). 추론은 자동 처리 자격 없음
- 질문의 답은 **재분류만** 한다. 어떤 답도 즉시 삭제를 유발하지 않는다
- '아니오/모르겠음'은 **항상 보존 쪽으로** 폴백
- 존 C는 스캔조차 하지 않는다(`SKIP_DIRS`) — 실수의 여지를 원천 차단
