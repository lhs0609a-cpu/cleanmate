# 테라클린 커뮤니티·광고 구현

## 구현한 것
- 앱의 커뮤니티 탭: 별도 온라인 커뮤니티를 앱 안에서 표시. 탭을 열기 전에는 커뮤니티를 불러오지 않음.
- 웹 커뮤니티 `/community.html`: 질문과 도움, 정리 팁, 정리 후기, 글 목록·상세·댓글·페이지 더 보기.
- 가입 없이 닉네임과 삭제 비밀번호로 작성. 운영자 검수 전에는 공개 API로 읽을 수 없음.
- 글·댓글 삭제, 신고, 관리자 공개/숨김 처리. 삭제 비밀번호는 솔트와 scrypt 해시로 보관.
- 운영자 `/admin.html`의 커뮤니티·광고 탭: 검수 대기/신고 목록과 후원 배너 등록.
- 후원 광고: 광고 표시, 광고주·문구·HTTPS 링크, 참고용 노출/클릭 집계. 활성 광고가 없으면 배너를 표시하지 않음.
- 무료 다운로드 버튼의 최신 버전 표시도 함께 구현. 동일 출처 최신 릴리스 API가 실패하면 GitHub 공개 API로 재시도.

## 현재 실제 상태
운영 Vercel 프로젝트 환경변수 목록을 확인했으며 등록된 환경변수가 없었다. 따라서 실제 게시글 저장과 관리자 로그인은 아직 운영 연결 전이다. 광고 계정 또는 직접 광고주 계약도 확인되지 않았다. 지금 광고 수익이 발생한다고 표시하지 않는다.

커뮤니티 구현은 로컬 소스·웹 빌드에 반영했다. 기존 설치파일 v0.26.1은 이번 작업으로 자동 변경되지 않는다. 저장소 연결과 운영 확인 후 새 Windows 설치파일을 빌드·릴리스해야 기존 설치 사용자도 커뮤니티 메뉴를 사용할 수 있다.

## 운영 연결에 필요한 설정
Vercel의 해당 프로젝트 환경변수에 직접 입력한다. 비밀값을 채팅·스크린샷·저장소에 넣지 않는다.

| 환경변수 | 용도 |
| --- | --- |
| UPSTASH_REDIS_REST_URL | 커뮤니티·문의 저장소 REST 주소 |
| UPSTASH_REDIS_REST_TOKEN | 해당 저장소 서버 접근 토큰 |
| ADMIN_PASSWORD | 관리자 로그인 비밀번호 |
| ADMIN_SESSION_SECRET | 관리자 세션 서명용 무작위 비밀값 |
| GITHUB_TOKEN | 선택 사항: 최신 버전 조회 한도 개선용 |

저장소를 연결하고 환경변수를 적용한 뒤 재배포한다. 관리자 로그인 → 검수 대기 글 공개 → 웹/앱 커뮤니티 열람 → 댓글 → 신고/숨김 → 본인 삭제를 실제 저장소로 확인한다. 그다음 새 앱 버전을 릴리스한다.

## 광고 운영 방식
관리자가 직접 계약한 광고주의 배너를 켜고 끈다. 초기는 월 고정 후원 계약으로 시작할 수 있으나 가격·광고주·보장 노출수는 아직 정하지 않았다. 노출과 클릭 숫자는 클라이언트가 전송한 참고 집계이며 고유 사용자 수나 확정 매출, 광고비 청구 기준이 아니다. 배너를 저장할 때 새 캠페인 ID로 집계를 시작한다.

Google AdSense 코드는 넣지 않았다. 소프트웨어 내부 게재에는 제한이 있으므로, 웹용 매체 승인과 데스크톱 앱 광고 허용 여부를 확인한 뒤 별도로 연동해야 한다.

- https://support.google.com/adsense/answer/48182?hl=en
- https://support.google.com/adsense/answer/1355699?hl=en

## 검증
API 검증은 모의 저장소 응답으로 실행했다. 실제 Redis의 Lua 실행·운영 데이터 저장·광고 정산 검증을 대체하지 않는다. 공개 전 검수, 비밀번호 비노출, 광고 설정 관리자 보호, 잘못된 광고 URL 거부, 저장 실패 응답을 확인했다.

브라우저 검증 역시 테스트 API를 사용했다. PC/모바일에서 빈 게시판·작성 접수·접수 번호·댓글·텍스트 이스케이프·후원 표시·저장소 미연결 안내·앱 내부 커뮤니티 표시를 확인했다. 결과 화면 파일은 테스트 데이터에 대한 캡처다.
